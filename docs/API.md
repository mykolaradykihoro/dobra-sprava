# REST API — «Добра Справа»

Base URL локально: `http://localhost:3001/api`.

| Метод | URL | Призначення | Успішна відповідь | Помилки |
|---|---|---|---|---|
| GET | `/health` | Перевірка стану сервера | 200 | — |
| GET | `/items` | Перелік зборів | 200 | 500 |
| GET | `/items/:id` | Один збір зі звітами | 200 | 404, 500 |
| POST | `/items` | Створення збору | 201 | 400, 500 |
| PUT | `/items/:id` | Оновлення збору | 200 | 400, 404, 500 |
| DELETE | `/items/:id` | Видалення збору | 204 | 404, 500 |
| POST | `/items/:id/donations` | Додавання демонстраційної суми | 200 | 400, 404, 500 |
| POST | `/contact` | Збереження звернення | 201 | 400, 500 |

## Приклад POST /items

```json
{
  "title": "Допомога медичному підрозділу",
  "goalAmount": 100000,
  "collectedAmount": 0,
  "description": "Збір на необхідне медичне обладнання та витратні матеріали.",
  "category": "Медицина",
  "status": "active"
}
```

Обов'язкові поля: title (від 5 символів), goalAmount (> 0), description (від 15 символів), category. Статус: `active`, `completed` або `paused`.

## Приклад POST /contact

```json
{
  "name": "Олена",
  "email": "olena@example.com",
  "phone": "+380671234567",
  "topic": "Питання щодо збору",
  "message": "Підкажіть, будь ласка, деталі ініціативи.",
  "consent": true
}
```

Контактні дані у прикладі вигадані. У навчальному середовищі звернення записуються в `server/data/messages.json`.

## Middleware
CORS для frontend origin, JSON body parser з обмеженням 100 KB, журналювання методу/URL, захисні заголовки, 404 для невідомих маршрутів, централізована обробка 400/500.

## Навчальна симуляція внеску
`POST /items/:id/donations` приймає `{ "amount": 200 }` (від 1 до 100 000) і збільшує поле `collectedAmount` у JSON. Реального платежу немає.
## Обробка помилок і відповіді сервера

API використовує стандартні HTTP-коди для позначення результату виконання запитів.

| HTTP-код | Значення | Опис |
|---|---|---|
| 200 | OK | Запит успішно виконано |
| 201 | Created | Новий ресурс створено |
| 204 | No Content | Ресурс успішно видалено |
| 400 | Bad Request | Некоректні або неповні дані запиту |
| 404 | Not Found | Збір або маршрут API не знайдено |
| 500 | Internal Server Error | Внутрішня помилка сервера |

У разі помилки API повертає JSON-об'єкт із текстовим описом проблеми. Для помилок валідації додатково може повертатися масив `errors` із переліком виявлених недоліків.

### Правила демонстраційних внесків

Маршрут `POST /api/items/:id/donations` має такі обмеження:

- сума внеску повинна бути числом від 1 до 100 000 грн;
- збір повинен існувати;
- збір повинен мати статус `active`;
- після успішного запиту оновлюється поле `collectedAmount`;
- сервер повертає ознаку `demo: true`;
- реальні платіжні операції не виконуються.

### Налаштування середовища

Сервер використовує такі змінні середовища:

| Змінна | Призначення | Значення за замовчуванням |
|---|---|---|
| `PORT` | Порт HTTP-сервера | `3001` |
| `CLIENT_ORIGIN` | Дозволене джерело запитів CORS | `http://localhost:5173` |

Для локального запуску параметри можна задати у файлі `.env` у папці сервера.
