# Використання AI-інструментів

| Інструмент | Промпт / задача | Отриманий результат | Ручна перевірка / виправлення |
|---|---|---|---|
| ChatGPT | «Створи структуру навчального React + Vite сайту для волонтерських зборів: головна, каталог, деталі з прогресом і звітами, контакти». | Запропоновано дерево компонентів і маршрути. | Відкориговано модель під варіант № 21; додано чітке маркування демонстраційних платежів. |
| ChatGPT | «Побудуй Express REST API CRUD із JSON-файловим сховищем і валідацією контактної форми». | Підготовлено серверні маршрути, сховище та функції перевірки. | Перевірено коди 200/201/204/400/404/500, нормалізацію сум, обробку помилок і заборону вигадувати реальні транзакції. |
| ChatGPT | «Поясни логіку прогрес-бару, custom hook для Fetch та debounce пошуку». | Підготовлено `ProgressBar`, `useCampaigns` та клієнтську фільтрацію. | Перевірено межі відсотка 0–100, очищення таймера, loading/error/empty states і доступні ARIA-атрибути. |

AI використовувався як допоміжний інструмент для генерації стартового коду й документації. Перед здачею студент має самостійно запустити проєкт, перевірити поведінку, пояснити компоненти та внести власні правки.
