# Технічне завдання — «Добра Справа»

## Призначення
Навчальний вебзастосунок для представлення волонтерських кампаній. Основна сутність — **Збір**. Обов'язкова особливість варіанта № 21: динамічний прогрес-бар суми та звіти про витрати.

## Цільова аудиторія
- Благодійник: шукає ініціативу, оцінює мету, прогрес і прозорість.
- Організатор: представляє потребу та публікує звіти про витрати.
- Відвідувач: переглядає каталог і контактує з командою.

## Сторінки
1. `/` — головна: представлення платформи, рекомендовані кампанії, переваги.
2. `/catalog` — каталог: пошук, фільтри категорії та статусу, сортування.
3. `/items/:id` — деталі: опис, сума, ціль, прогрес-бар, організатор, звіти та тестовий сценарій підтримки.
4. `/contacts` — форма зворотного зв'язку.
5. `*` — 404.

## Функціональні вимоги
- F1 — перелік активних і завершених зборів.
- F2 — деталі окремої кампанії.
- F3 — цільова та зібрана суми.
- F4 — динамічна шкала прогресу з відсотком.
- F5 — пошук за назвою/описом/категорією (debounce 300 мс).
- F6 — фільтрація за категорією та статусом.
- F7 — звіти про витрати з датою, описом та сумою.
- F8 — контактна форма з клієнтською і серверною валідацією.
- F9 — CRUD зборів через REST API.
- F10 — перемикання Light/Dark та збереження вибору.
- F11 — демонстраційне збільшення зібраної суми без платіжної операції.

## Нефункціональні вимоги
Mobile-first; цільові ширини 360, 768, 1280 px; семантичні елементи; видимий focus; клавіатурна навігація; альтернативні тексти; обробка помилок; оптимізація збірки; відсутність секретів у Git.

## Модель даних
`id`, `title`, `goalAmount`, `collectedAmount`, `description`, `shortDescription`, `category`, `status` (`active | completed | paused`), `organizer`, `reports[]`, `createdAt`, `updatedAt`.

## Стек
React + Vite, React Router, JavaScript ES modules, CSS3, Tailwind CSS utility classes, Node.js, Express, CORS, dotenv, JSON file storage, Vitest, React Testing Library.

## Межі прототипу
Кампанії та цифри у `server/data/campaigns.json` демонстраційні. Функція внеску лише додає тестове число до JSON. Платіжного провайдера, фінансових транзакцій, підтвердження організаторів і реального збору пожертв немає.
