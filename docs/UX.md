# UX/UI-проєктування

## Персони

**Персона 1 — благодійник.** Вік: 18–45 (умовна гіпотеза для проєктування, не результат опитування). Мета — швидко знайти потрібну ініціативу, оцінити поточний прогрес і перевірити звітність. Проблеми — перевантажені сторінки, неясна ціль збору, відсутність звітів. Основний пристрій — смартфон.

**Персона 2 — організатор.** Вік: 20–55 (умовна гіпотеза). Мета — зрозуміло представити збір і пояснити витрати. Проблеми — потреба регулярно оновлювати суми та звіти, різний рівень цифрових навичок. Пристрій — смартфон або ноутбук.

## User stories
1. Як відвідувач, хочу бачити актуальні збори на головній, щоб швидко знайти ініціативу.
2. Як користувач, хочу шукати за назвою, щоб знайти потрібну кампанію.
3. Як користувач, хочу фільтрувати за категорією та статусом, щоб звузити перелік.
4. Як благодійник, хочу бачити прогрес, щоб оцінити стан збору.
5. Як благодійник, хочу переглядати звіти про витрати, щоб розуміти, на що спрямовано кошти.

## User flow
Головна → Каталог → Пошук/фільтр → Деталі кампанії → Перегляд суми, прогресу та звітів. Альтернативний шлях: Головна → Контакти → Валідація форми → Повідомлення про результат.

## Дизайн-система, реалізовані токени
- Primary: темно-зелений `#174C3C`; secondary: `#286C52`; accent: теплий жовтий `#F2BD66`.
- Фон: `#F7F8F3`; поверхня: `#FFFEFA`; текст: `#19372E`; нейтральний текст: `#718078`.
- Відступи: 4, 8, 12, 16, 24, 32, 48, 64 px.
- Радіуси: 6, 10, 14 px.
- Типографіка: системний sans-serif для тексту; Georgia для акцентних заголовків.
- Теми: світла та темна через CSS custom properties і `data-theme`.

Header, Footer, Button, CampaignCard, CampaignList, ProgressBar, Modal, ContactForm, ThemeToggle. Компоненти реалізовані у `client/src/components/`.
