# Тестування та аудит

## Автоматизовані тести

Для клієнтської частини додано 7 тестів Vitest:
- коректна контактна форма;
- перевірка короткого імені;
- перевірка email;
- перевірка формату телефону;
- перевірка довжини повідомлення;
- перевірка обов'язкової згоди;
- рендер ProgressBar та перевірка `aria-valuenow`.

Запуск: `cd client && npm test`.

## Адаптивність

CSS містить mobile-first стилі та контрольні breakpoint 768 px і 1280 px. Під час здачі треба зробити скриншоти реального відображення на 360, 768 та 1280 px у світлій і темній темах.

## Залишилося перевірити вручну

- виконати всі TC-01—TC-17 і внести фактичні результати;
- запустити Lighthouse (mobile) для головної та каталогу, зберегти JSON/HTML звіти;
- перевірити axe DevTools і W3C Validator;
- протестувати service worker / встановлення PWA на реальному пристрої;
- після деплою замінити `example.com` у sitemap і robots на фактичний домен.
